# Farmer-Rescue-Game
## Overview

Farmer Rescue is a Python-based educational adventure game that challenges players to help farmers survive natural disasters and environmental challenges. players must rescue stranded farmers, collect resources, aviod hazards, and reach safe zones before time runs out.
The project was created to combine programming, problem-solving, and awareness of real-world challenges faced by farming communities. 

## Pronblem Statement 

Many communities in my country, South Sudan depend on agriculture for their livelihoods. Flood, drought, and other environmental disasters threatens farmers, crops, and food security.
This game aim is to raise awareness of these challenges through an interactive and engaging experiences.

## Features

Player movement and navigaion. 
Enviromental hazards.
Farmer rescue missions.
Score tracking system.
Win and lose conditions. 
Increasing difficulty levels.
Replayability.

## Technologies Used

Python 3
pygame

## Game Objectives

The player must :
1. Find stranded farmers.
2. Rescue as many as possible.
3. Avoid dangerous obstacle.
4. Reach the designated safe zone.
5. Earn the heighest score possible.
